# UI polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Apply Thomas's screen-review decisions and the card look to every screen, and bring the timer and complete
screens closer to their mockups.

**Architecture:** Cards only (Lit). Each step's template and styles live in `cards/src/flow/<step>.ts`, shared styles
in `cards/src/flow/shared.ts`, the ring in `cards/src/ring.ts`, the today card in `cards/src/today-card.ts`. Texts come
from `cards/src/i18n/{en,da}.json`.

**Tech Stack:** Lit 3, TypeScript, Vitest + Testing Library (`@testing-library/dom` queries on the shadow root).

**Spec:** `docs/superpowers/specs/2026-10-24-ui-polish-design.md`

## Global Constraints

- **Texts:** every UI text comes from a language file, English the base and Danish too. Separators such as " · "
  live inside the keys, as `today.short_summary` does. Exercise names are never translated.
- **Tests:** they check rendered text and roles only. No snapshot or CSS-selector tests, no `tagName` checks, and no
  assertions on styles. Bold numbers are asserted with the ARIA role `strong` (aria-query maps `<strong>` to it).
- **Button heights stay:** 48 px normal, 64 feeling, 72 / 104 timer, 96 main.
- **The card look:** HA's light theme through HA's CSS variables. `background: var(--card-background-color, #fff)`,
  `border: 1px solid var(--divider-color)`.
- **Text colours:** work `#B54708`; switch, rest and countdown `#1F5FAD`. `RING_COLORS` stays as it is.
- **Gates before each commit:** `npm run lint --prefix cards && npm test --prefix cards && npm run build --prefix
  cards`.
- **Commits:** Conventional Commits with the co-author trailer from the dispatch, using `git commit -F <file>`.

## Review Focus

- **A two-person session in the today card:** line 2 joins the two names with "og". A test pins it in Task 1.
- **A planned time that isn't whole minutes:** the running row rounds as get ready does (nearest minute). A test pins
  it in Task 1.
- **An older add-on without `totals.stations`:** the pills show only the current number, with no "/". A test pins it
  in Task 3.
- **`equipment: []` against no `equipment`:** "Intet udstyr" against hidden. Tests pin both in Task 2.
- **A double tap on Spring over:** the second tap lands on Nej. The reviewer checks that Start and Ja share a width and
  that Spring over and Nej share `.slot`. The Chrome check confirms it.
